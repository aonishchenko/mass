## What MASS is, in 30 seconds

**Every AI agent today is single-player.** One person, one private chat, one
owner. But the knowledge that makes an agent genuinely good is *collective* — it
lives in the heads of the two or three people on a team who have watched users
fail, and it leaves when they do.

**MASS is how a team builds an AI colleague together, and provably co-owns what
it becomes.** A crew of verified humans teaches a shared agent. Every accepted
contribution is attributed on an immutable log. Ownership is computed from that
log — never assigned by hand. And when the agent is hired, its fee flows back to
the humans whose knowledge it actually used.

> **The agent cites its teachers. By name.**

---

## The problem

If a team is going to pour its hard-won expertise into an agent and own the
result, three things have to be true — and on today's AI stack, none of them are:

1. **The knowledge has to be private.** Nobody teaches an agent their real
   judgement if it lands in a vendor's training set.
2. **The knowledge has to be an asset.** Something with an owner, a hash, a
   history — transferable, not a row in a SaaS account.
3. **The thinking has to be verifiable.** If an answer earns money and assigns
   credit, "trust us, it ran correctly" is not good enough.

An agent whose brain lives in someone else's product isn't co-owned. It's rented.

## The solution

0G is the **brain, the compute, and the identity** of MASS:

- The agent's brain is **curated, first-party-encrypted memory on 0G Storage** —
  hash-linked version to version, so its history is verifiable and it is a real
  asset the crew holds.
- Answers that count run **sealed on 0G Compute**, in a TEE. When the provider
  returns an attestation for that run we show it; when it does not, we show the
  run reference and say plainly that no attestation was returned.
- The agent is minted as an **Agentic ID (ERC-7857)** its crew co-owns.

And because every brain chunk carries its contributor, the agent **cites the
humans who taught each answer**.

## How people use it

| # | What the user does | What 0G does |
|---|---|---|
| 1 | Chats with the agent to explore | The **draft lane** streams fast on a standard key |
| 2 | Marks something worth keeping; the crew co-signs | The chunk is screened, then written to the **encrypted brain** on 0G Storage |
| 3 | Asks a question that counts | The **canonical lane** runs **sealed** in a TEE |
| 4 | Reads the answer | It cites its teachers — *"(per `alice.mass.eth`'s contribution #7)"* |
| 5 | Clicks the run chip | The attestation for that response if 0G returned one — otherwise the endpoint, model and response id, labelled as a run reference, not a proof |
| 6 | Closes the session | The brain is sealed, the full log archived, the **Agentic ID** minted with the crew delegated as co-owners |

Two lanes matter: throwaway thinking is fast and cheap, and anything that becomes
permanent brain — or earns money — runs sealed.

## 0G features, put in practice in order to…

- **…make a brain that is an asset, not a database row.** Every version has a
  root hash, links to its predecessor, and is encrypted with a key we never
  hand over. That root hash is published in the agent's ENS record and anchored
  on Hedera — so the brain's identity is portable and verifiable from outside.
- **…let people teach an agent things they would never paste into a chatbot.**
  Sealed execution plus first-party encryption is what makes confidential
  expertise contributable at all.
- **…keep the claim exactly the size of the evidence.** A sealed run is executed
  with the TEE key and reports the attestation the provider gives us. If a run
  degrades to unsealed, the UI says so in a banner. If no attestation comes
  back, we show a run reference instead and call it that. We never mint our own
  receipt — a self-issued proof is worth less than none.
- **…defend the brain from what it is taught.** Each proposed contribution is
  screened before acceptance, with the verdict logged, so the crew's asset can't
  be quietly poisoned.
- **…make co-ownership real on-chain.** The Agentic ID mints with delegated
  crew users, so "we own this together" is enforced by the asset, not by us.

> **We say it precisely:** the brain is *curated encrypted memory, instructions
> and skills* — **not** weight training. On-platform fine-tuning is the natural
> next step for this same asset, and we don't claim it today. Likewise it is
> **TEE attestation of sealed execution**, never "ZK-proven."

---

## Why 0G is load-bearing here

0G is what makes MASS an *asset* rather than a chat. Take it out and the brain
becomes a vendor's database (unownable), confidential knowledge stops being
contributable (nobody teaches it anything real), the answers become unverifiable
(so paying for them is faith), and there is no identity to co-own. The other
integrations prove *who* and *how much*; 0G is *the thing being owned*.
